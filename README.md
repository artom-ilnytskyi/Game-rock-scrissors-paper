# Rock Paper Scissors Game (Python)

A lightweight, interactive **Rock Paper Scissors** game written in **Python**. Play the classic hand game against a computer bot that makes intelligent, randomised moves!

## 🚀 Features
* **Score Tracking:** Real-time score updates for both the player and the bot after each round.
* **Best of 3 Match:** The game follows a **first-to-3 points** system to determine the ultimate winner.

## 🛠️ Tech Stack
* **Language:** Python 3.x
* **Core Modules:** `random`

## 🎮 How to Play
1. Run the script in your terminal.
2. Enter your choice: **Rock**, **Paper**, or **Scissors** - not use space, only word
3. The robot will simultaneously make its random choice.
4. The system calculates the winner and updates the score.
5. The game ends as soon as either you or the robot reaches **3 points
